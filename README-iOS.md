# 大花截圖記錄：iPhone 版

這是獨立於 `pikmin-flower-route` 的新版本。兩個資料夾的程式碼與新資料儲存鍵互不影響；若瀏覽器能讀到舊版資料，新版第一次開啟時只會複製一份，不會修改舊版。

## 建議使用流程

1. 在 Pikmin Bloom 依序查看大花並截圖。
2. 打開「大花截圖記錄」，按地圖左上角的「選截圖」。
3. 一次選取剛才的多張截圖。
4. 對照右上角截圖，點地圖上的固定花點。
5. 在底部輸入剩餘時間，按 iPhone 鍵盤的「完成」或按「儲存」。
6. 儲存後會自動前往下一張；也可用左右箭頭切換。
7. 按「完成並移除這張」可從本次批次中移除截圖。截圖只暫存在記憶體，不會存進網站資料。

## 加入 iPhone 主畫面

PWA 與離線快取需要從 HTTPS 網址開啟，直接點本機 `index.html` 不會啟用 Service Worker。

1. 將整個資料夾部署到 HTTPS 靜態網站。
2. 用 iPhone 的 Safari 開啟網址。
3. 點 Safari 的分享按鈕。
4. 選「加入主畫面」，並開啟「作為 Web App 開啟」。
5. 第一次連線開啟後，程式與目前這份離線地圖會快取在手機上。

固定花點與開花時間保存在該 iPhone 的網站資料中。清除 Safari 網站資料會一併清除記錄。

## 三組離線地圖

- 第一次開啟會顯示程式預設地圖；使用者第一次設定中心後，新地圖會直接取代預設圖，成為地圖 1。
- 地圖 1、2、3 都可修改，總數最多三組。
- 使用者只需輸入地圖中心；每張地圖固定下載中心周圍 3 公里，不需選擇範圍。
- 修改或取代地圖時，新資料成功儲存後才會刪除舊圖資與該組花點。
- 每組地圖有自己的中心 `H`、活動邊界、固定花點與最後縮放位置。
- 地圖中央的 `H` 是該組中心；右下角 `◎` 可隨時回到目前地圖中心。
- 自訂地圖資料存放在 IndexedDB，花點與設定存放在該網站的瀏覽器資料中。
